# Terminal Commands – Day 1

## 1. pwd
Shows the current working directory.

Example:
pwd

## 2. ls
Lists files and folders in the current directory.

Example:
ls

## 3. cd
Changes the current directory.

Example:
cd Python-30-Days

## 4. cd ..
Moves to the parent directory.

Example:
cd ..

## 5. mkdir
Creates a new folder.

Example:
mkdir Projects

## 6. cls
Clears the terminal screen.

Example:
cls

## 7. python --version
Displays the installed Python version.

Example:
python --version

## 8. python
Opens the Python interactive shell.

Example:
python

## 9. git status
Shows the Git repository status.

Example:
git status

## 10. exit
Exits the Python interactive shell.

Example:
exit
